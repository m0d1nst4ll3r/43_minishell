# Minishell

[Subject](https://cdn.intra.42.fr/pdf/pdf/199852/en.subject.pdf)

## Description

Minishell is a small basic shell that mimics bash and allows its user to operate basic commands. It handles basic redirection (`< << >> >`), pipes `|`, environment variables (but not local variables) and contains a few built-in functions such as `cd`, `pwd`, `echo`, `export`, `env`, `unset`, and `exit`

## Instructions

1. Run make
2. Run minishell

```
make
./minishell
```

You can test memory with `make valgrind`
